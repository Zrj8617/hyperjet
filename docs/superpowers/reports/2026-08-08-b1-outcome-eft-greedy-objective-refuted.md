## 3. 关于 `classification = hard_sharpening_only` 的解读

这个分类**不代表存在剩余的集中度问题**，它是判据失效的产物。

失败点**不在 margin20**：sampled `margin20_accuracy` 在 T=1.0 就已经是
**0.9968 – 0.9983**，全部温度满足 ≥0.90。

卡住的是 `static_temperature_gate` 中 `common_pass` 的另一条：
**regret_reduction ≥ 0.50（至少 2/3 checkpoint）**。

| 温度 | regret reduction（三 seed） | 结果 |
| --- | --- | --- |
| 0.25 | 0.600 / 0.587 / 0.595 | 通过 |
| 0.50 | 0.480 / 0.458 / 0.470 | 未通过 |
| 0.75 | 0.283 / 0.262 / 0.264 | 未通过 |

而基线已经坍缩：

```
sampled_mean_EFT_regret @ T=1.0：  旧 57–60 s  →  新 0.354 – 0.428 s
deterministic mean EFT regret：     旧 23–26 s  →  新 0.127 – 0.155 s
候选间 top-2 时延差中位数：          7.4 s
DAG 平均流时间：                    约 190–220 s
```

要求从 0.35 秒再降 50%，等于在量噪声。该阈值是在「后悔 60 秒」的量级下定的，
**前提消失后判据已失去区分力**。

**判据修订（记录在案）**：`regret_reduction ≥ 0.50` 应附加绝对下限，
例如「仅当基线 `sampled_mean_EFT_regret > 5 s` 时适用」。
按此修订，**温度通道判定为关闭且无需再追**。

同时：Part A 的 `expected_range_pass: false` **不是失败**——
该检查的期望区间（饱和 0.53–0.61）是 B1 之前的预测值，实测远在其上，检查本身已作废。

补充理由：Stage 2 中采样策略即行为策略，需要探索。
当前熵 0.201–0.215、`max_action_probability` 0.870–0.877 属健康探索水平，
刻意压向 0 反而有害。

## 4. 解释假设（**尚未验证**）

B1 前的诊断显示：约 70–80% 的决策中 `incremental_delay` 全被截为 1.0，
判别信息只能来自 dynamic 特征中的队列相关维（`queue_length/16`、`queued_workload`）。

此前我把这描述为「退化为代理策略」。**该描述方向错误。**

> **「选队列最短的 UAV」不是退化，它是一个更好的负载均衡策略。**

```
B1 前：特征被截断 → 策略 ≈ 最短队列优先 → 负载均衡 → 吞吐 108
B1 后：特征恢复   → 策略 ≈ 最小 EFT     → 短视、羊群效应 → 吞吐 92
```

机制：EFT-greedy 逐任务地把工作推向「当前看起来最快」的 UAV。
`TemporaryReservationState` 虽然在时隙内即时更新状态、缓解了同时隙冲突，
但目标函数本身不含任何跨任务或跨时隙的负载均衡考量。

**状态：假设，未验证。不得作为结论引用。**

### 验证方案（当前最高优先级）

在同一条冻结 tape 的**全部 20 个场景**上运行两个手写启发式，与本轮结果配对比较：

| 启发式 | 若假设成立的预期 |
| --- | ---: |
| 最短队列优先 | ≈ 108 |
| greedy-EFT | ≈ 92 |

工具已就绪（启发式策略评估框架，第 2 轮已完成并通过 16 项验证锚点）。
不训练任何模型，纯 CPU。

## 6. 对论文的影响

本轮提供了一段**可量化、实验得来**的动机论证：

> 我们首先构造了一个近乎完美的短视调度器：在 margin≥20 s 的决策上，
> 其 EFT 排序准确率达 99.9%，平均 EFT 后悔仅 0.13 s。
> 然而其闭环 DAG 完成量比排序信息受限的版本低 15%（配对 t = −14.4，20 场景中 16 个下降）。
> 这表明在多 DAG 共享资源的场景中，逐任务最小化完成时间是次优的：
> 调度必须显式建模跨任务的资源耦合与 DAG 级前瞻。

这直接支撑高阶表示与长视野学习的必要性，比单纯声称「超图能捕捉高阶关系」有力得多。

### ⚠️ 诚实性红线

**B1 之前那个吞吐 108 的策略是特征截断缺陷的副产物，不是设计产物。**

论文中**不得**表述为「我们的方法比 greedy-EFT 好 15%」。

正确路径：用**有意设计的**基线（最短队列 / 负载均衡启发式）证明 EFT-greedy 次优，
再要求本方法超过该基线。这使 §4 的验证批次成为论文论证链条上的必要环节，
而非可选的补充实验。
